Answers for the Verb conjugation packet packet. Teachers only — the packet page itself has no answers on it.

hablar present blanks

tú = hablas; nosotros = hablamos; ellos = hablan

comer present blanks

yo = como; tú = comes; ellos = comen

vivir present blanks

tú = vives; él/ella = vive; nosotros = vivimos

1B. Present answers

to hug present, yo = abrazo; to applaud present, tú = aplaudes; to move forward present, él/ella = avanza; to help present, nosotros = ayudamos; to kiss present, ellos = besan; to box present, yo = boxeo; to search present, tú = buscas; to walk present, él/ella = camina

1C. Family answers

cantar = -ar; beber = -er; escribir = -er; bailar = -ar; subir = -ir; cocinar = -ar; aprender = -er; vivir = -ir; hablar = -ar

2A. Hablar preterite blanks

yo = hablé; él/ella = habló; ellos = hablaron

2B. Preterite answers

to speak preterite, tú = hablaste; to speak preterite, él/ella = habló; to eat preterite, tú = comiste; to eat preterite, nosotros = comimos; to live preterite, yo = viví; to live preterite, ellos = vivieron; to be preterite, yo = fui; to have preterite, él/ella = tuvo; to speak preterite, nosotros = hablamos; to eat preterite, yo = comí; to live preterite, él/ella = vivió; to have preterite, ellos = tuvieron

3A. Future answers

to speak future, nosotros = hablaremos; to eat future, yo = comeré; to live future, tú = vivirás; to speak future, ellos = hablarán; to eat future, él/ella = comerá; to live future, nosotros = viviremos; to speak future, yo = hablaré; to eat future, ellos = comerán; to live future, él/ella = vivirá; to speak future, tú = hablarás

3B. Yo future answers

abrazar → abrazaré; aplaudir → aplaudiré; avanzar → avanzaré; ayudar → ayudaré; besar → besaré; boxear → boxearé

ser table blanks

Present: tú = eres; nosotros = somos. Preterite: tú = fuiste; nosotros = fuimos

estar table blanks

Present: yo = estoy; él/ella = está. Preterite: yo = estuve; él/ella = estuvo

ir table blanks

Present: tú = vas; ellos = van. Preterite: tú = fuiste; ellos = fueron

tener table blanks

Present: yo = tengo; nosotros = tenemos. Preterite: yo = tuve; nosotros = tuvimos

hacer table blanks

Present: él/ella = hace; ellos = hacen. Preterite: él/ella = hizo; ellos = hicieron

4B. Future stem answers

tener → tendré; poder → podré; querer → querré; saber → sabré; poner → pondré; salir → saldré; venir → vendré; decir → diré; hacer → haré

4C. Irregular answers

to be present, él/ella = es; to be present, yo = estoy; to go present, tú = vas; to have present, ellos = tienen; to do / to make preterite, yo = hice; to be preterite, nosotros = fuimos

5. Review quiz answers

to speak present, tú = hablas; to eat preterite, él/ella = comió; to live future, yo = viviré; to be present, ellos = son; to have preterite, tú = tuviste; to speak future, nosotros = hablaremos; to eat present, yo = como; to be preterite, él/ella = estuvo; to live preterite, ellos = vivieron; to do / to make future, tú = harás

6. Reflection

Open answers — any thoughtful response counts.

For the teacher

Purpose: the packet version of the Verb Conjugation tool — same 113 verbs, same Latin-American forms, now as paper practice. Timing: about 50 minutes, or one section per day across four days. Tip: teach Section 4 last; students who try to memorize irregulars before the regular patterns struggle more. The shared ser/ir preterite is the detail students most often miss.
